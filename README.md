# Calculadora para colheita de café

## Como usar

- Coloque o nome do panhador, se quiser, ou pule, se não quiser
- Insira o preço por latão
- Insira quantos latões o panhador colheu, você pode colocá-los em forma de soma também
- Insira quantos litros o panhador colheu, você pode colocá-los em forma de soma também
- Você pode adicionar mais panhadores ou concluir
- Ao concluir, uma tabela será gerada, que pode ser exportada e compartilhada ou baixada
- Para reiniciar, recarregue a página ou pressione o botão reiniciar, abaixo da tabela
